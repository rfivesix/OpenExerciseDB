# Reports

These reports describe the current state of the catalog data. All five generated reports can be regenerated from the repository root with `PYTHONPATH=. python3 build/generate_reports.py`.

- [curation_notes.md](curation_notes.md) — Durable schema and contribution guidance retained from the former session handover; manually maintained.
- [invariant_20_outliers.md](invariant_20_outliers.md) — Movement-pattern and primary-muscle outliers explaining the 36 known Invariant 20 warnings in the catalog.
- [family_consistency.md](family_consistency.md) — Classification differences and variations within exercise families.
- [unclassifiable.md](unclassifiable.md) — Missing classification attributes and unresolved exercise cases (e.g. cardio, stretches, warm-ups).
- [name_overrides.md](name_overrides.md) — Heuristic conflicts between exercise names and primary muscle assignments.
- [cross_language.md](cross_language.md) — Heuristic English/German text discrepancies in the catalog.
